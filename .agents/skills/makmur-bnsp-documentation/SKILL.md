# Makmur BNSP Documentation

## When to Use
- Creating or updating BNSP-required documents
- Auditing documentation completeness

## Coverage
- Architecture
- Hardware specification
- Tool analysis
- Scalability analysis
- Security risk analysis
- Migration plan
- Cutover plan
- Impact analysis
- User guide
- FAQ
- API documentation
- Troubleshooting guide

## Procedure
1. Identify which documents are required or missing.
2. Gather current implementation facts and constraints.
3. Draft each document with concrete, verifiable details.
4. Cross-check claims against code and configs.
5. Mark simulations or assumptions explicitly.
6. Update docs index if present.

## Output
- Document checklist with status
- Drafts or updated files
- Any assumptions called out

## Quality Checks
- No claims exceed implemented features
- Sensitive data is excluded
- Documents are consistent and traceable
